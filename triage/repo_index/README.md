# TRIAGE offline repository index

This directory defines the deterministic repository-census surface generated by
`scripts/repo_artifact_index.py`.

The census outputs are **generated evidence, not canonical source**. They are no
longer committed to Git. Generate them locally when needed, or use the
`TRIAGE Repository Artifact Index` GitHub Actions artifact produced from the
tested SHA.

## Outputs

- `ARTIFACT_INDEX.yaml` — complete tracked-artifact census grouped by artifact
  type and alphabetically ordered by path within each type.
- `FILE_INDEX.tsv` — flat, grep-friendly inventory containing type, path, kind,
  size, SHA256, Git object and text-searchable flag.

The two generated files exclude themselves from the census to avoid recursive
hash churn. `indexed_source_sha` records the exact commit that was inventoried.

## Generate and verify locally

```bash
python scripts/repo_artifact_index.py --write
python scripts/repo_artifact_index.py --check
```

Because the files are ignored by Git, local generation does not dirty the
canonical source tree.

## Offline use

```bash
python scripts/repo_artifact_index.py --grep QPLANT
python scripts/repo_artifact_index.py --grep ALAT
python scripts/repo_artifact_index.py --grep 'ALAT|compliance|negotiation' --regex
python scripts/repo_artifact_index.py --grep RTM --case-sensitive
```

Normal local tools remain useful:

```bash
grep -i 'QPLANT' triage/repo_index/FILE_INDEX.tsv
rg -n -i 'ALAT|compliance|negotiation' .
```

Binary files remain fully indexed by path/type/size/hash but are deliberately
skipped by content grep.

## P1 hygiene decision

The 2026-10-02 repository-hygiene slice removed two classes from canonical Git:

- checked-in `venv/` environment/vendor state;
- committed `ARTIFACT_INDEX.yaml` and `FILE_INDEX.tsv` generated census output.

The generator, schema and README remain source-controlled. Generated census
files are reproduced from the exact SHA and carried as CI/local artifacts.

See `triage/repo_hygiene/P1_REPOSITORY_HYGIENE_CURRENT.yaml`.

## Authority rule

The index is discovery and modernization evidence. It does not promote a file to
QPS/ABACUS/CODEX authority. Candidate promotion still requires an exact-source
SHA, smoke/reproduction evidence, a unique-delta statement, target owner and
explicit disposition.
